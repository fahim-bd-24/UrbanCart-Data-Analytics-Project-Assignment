# UrbanCart Data Analytics Project

## Project Overview
UrbanCart is an online retail analytics project where SQL is used to analyze sales, customers, products, payments, and business operations.

## Objectives
- Analyze sales performance
- Understand customer behavior
- Identify top products
- Analyze cancellation trends
- Generate business insights

## Database Schema
ER Diagram shows the relationship between fact and dimension tables.

## Business Analysis
This project answers 25 business questions using SQL including:
- Monthly sales trend
- Customer analysis
- Product performance
- Cancellation rate
- Payment analysis
- Inventory insights

## Key Insights
- Identified top-performing products and categories
- Analyzed customer purchasing behavior
- Found cancellation trends by city and customer
- Evaluated payment method performance

## Recommendations
- Improve customer retention strategies
- Reduce cancellation rate
- Optimize inventory planning
- Focus on high-performing products
